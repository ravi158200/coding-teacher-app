# Full-stack-Teaching-websites
A full-stack teaching website built using ReactJS, Node.js, Express, and MongoDB (Mongoose) that allows users to access online courses, watch videos, and manage learning content. This platform includes user authentication, course upload, and an admin dashboard for managing educational materials.


🚀 Features

🔐 User Login & Signup Authentication

📚 Multiple Course Upload System

🎥 Video Course Player

👨‍🏫 Admin Panel for Course Management

🗂 Course Category & Course Details Page

❤️ Save / Enroll Course Option

🌐 Responsive Design for Mobile & Desktop

🛠 Tech Stack

Frontend: ReactJS, CSS, Bootstrap

Backend: Node.js, Express.js

Database: MongoDB with Mongoose

Authentication: JWT / Session

API: REST API

📂 Modules

User Authentication Module

Course Upload Module

Video Streaming Module

Admin Dashboard

Database Schema using Mongoose

🎯 Project Goal

The goal of this project is to create a complete online teaching platform where teachers can upload courses and students can learn from anywhere.
